# Cost-Control Rules

1. Use the currently selected model. Never switch to Opus or spawn subagents unless explicitly authorized.
2. Do not perform project-wide exploration. Read only files relevant to the requested task.
3. Do not repeat investigations already documented in project files.
4. Never rewrite working files unnecessarily.
5. Make only explicitly requested changes.
6. Do not generate lengthy explanations, duplicate code, or unnecessary reports.
7. Run only the requested validation.
8. Do not create temporary scene objects, screenshots, or assets unless requested.
9. Stop immediately if blocked. Report the issue instead of exploring unrelated alternatives.
10. Preserve existing working architecture and assets.

Prioritize minimal token consumption and minimal changes.
